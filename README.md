# port a beacon
1.21.1 branch

A fabric mod that cuts out the hassle of mining down your beacon and rebuilding it when you want to move it!
Simply Shift + Right Click your beacon in order to compact it and pick it up, and place it down at the new location to instantly rebuild it!

# DISCLAIMER

Beacon pyramids can only be picked up if it's all built out of one block. Multiple block types are not supported.
In addition, when the pyramid is being rebuilt, there is no safety for destroying nearby blocks. Be careful of where you rebuild your beacons!
